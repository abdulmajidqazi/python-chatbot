# 🤖 Python ChatBot

A simple command-line AI chatbot built with **Python** that uses **Ollama** to run the **Llama 3.2** model locally.

This project demonstrates how to interact with a locally hosted Large Language Model (LLM) using Python and the Ollama API.

## ✨ Features

- 💬 Chat with Llama 3.2 locally
- ⚡ Fast command-line interface
- 🔒 Runs completely offline
- 🐍 Simple and beginner-friendly Python code
- 🛠 Easy to customize and extend

## 🛠 Built With

- Python
- Ollama
- Llama 3.2
- Requests

## 📋 Requirements

Before running the project, make sure you have:

- Python 3.10 or later
- Ollama installed
- Llama 3.2 downloaded

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/abdulmajidqazi/python-chatbot.git
cd python-chatbot
```

Install the required packages:

```bash
pip install -r requirements.txt
```

---

## 📥 Download the Model

Download the Llama 3.2 model:

```bash
ollama pull llama3.2
```

---

## ▶️ Start Ollama

Start the Ollama server:

```bash
ollama serve
```

---

## ▶️ Run the ChatBot

```bash
python chatbot.py
```

Type your questions and press **Enter**.

To exit the chatbot:

```text
exit
```
